# SystemHive Optimizer - /Data mappa

Itt tároljuk a konfigurációs és szabály fájlokat.

## Fájlok

- **whitelist.json** → Sosem törlendő kulcsok és kategóriák
- **blacklist_patterns.json** → Mindig törlendő minták
- **system_profiles/** → Windows verzió specifikus beállítások

## Jövőbeli bővítési lehetőségek

- `custom_rules.json`
- `known_good_publishers.json`
- `version_specific/` mappa
- `exceptions/` mappa

A Cleaner és Scanner később ezeket automatikusan be fogja olvasni.
